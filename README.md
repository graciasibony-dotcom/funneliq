# FunnelIQ

Marketing-intelligence tool for Northbound Media — predicts customer
lifetime, upsell probability, and a "super customer" score from
funnel data, with ad budget optimization insights.

## Tech Stack
- Python 3.12
- FastAPI
- Supabase (Postgres + Auth)
- Railway (deployment)
- XGBoost / LightGBM / CatBoost
